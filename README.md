A lightweight, high-performance web application that delivers inspiration from the world of Anime. Built using Vanilla JavaScript and modern API integration techniques.

---

## 🎯 The Technical Challenge
The goal of this project was to create a seamless user experience while fetching data from a third-party REST API. It demonstrates:
* **Async/Await Logic:** Managing network requests without blocking the UI thread.
* **DOM Injection:** Dynamically updating the quote, character name, and anime title without page refreshes.
* **Mobile-First Design:** A fully responsive CSS layout that looks great on any screen size.

## ✨ Features
* **Instant Fetch:** Get a new random quote with a single click.
* **Responsive UI:** Clean, distraction-free interface focused on readability.
* **Error Resilience:** Graceful handling of API fetch failures.

## 🛠️ Tech Stack
* **Languages:** HTML5, CSS3, JavaScript (ES6)
* **Deployment:** Hosted on **Render** (Static Site Service)
